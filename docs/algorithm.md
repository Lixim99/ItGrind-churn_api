# Как работает pipeline

1. CSV проверяется по схеме `DatasetRowChurn`. Все столбцы обязательны;
   пропущенные значения признаков допускаются, пропущенная цель — нет.
2. Из данных выделяются X и y. Список и порядок признаков заданы в `src/core/config.py`.
3. Стратифицированное разбиение выделяет 20% строк в test с seed 42.
   Обе части должны содержать оба класса churn.
4. На train обучается ColumnTransformer: числовые признаки проходят
   SimpleImputer(median) и StandardScaler, категориальные —
   SimpleImputer(most_frequent) и OneHotEncoder(handle_unknown="ignore").
5. Классификатор LogisticRegression или RandomForestClassifier обучается
   в едином Pipeline. Функция `train_churn_model` не зависит от FastAPI.
6. На test считаются accuracy, F1 и ROC AUC. Pipeline, конфигурация, время,
   метрики и порядок признаков сохраняются в joblib; запись обучения — в JSON.
7. При старте pipeline загружается в память. `/predict` проверяет запрос,
   выстраивает столбцы в сохранённом порядке, вызывает predict/predict_proba.
   Ответ содержит метки и вероятности обоих классов для каждого клиента.

Заполнение пропусков и масштабирование не используют тестовую выборку.
Тестовые значения не меняют обученные статистики преобразований.
